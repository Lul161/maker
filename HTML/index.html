5. 电子焊接

焊接练习：LED闪烁电路

焊接步骤：

  1. 准备工具：电烙铁、焊锡、松香、助焊剂
  2. 给电烙铁预热（约300°C）
  3. 先给焊盘和元件脚上锡
  4. 将元件固定在电路板上
  5. 焊接每个焊点，约2-3秒
  6. 检查有无虚焊、短路

💡 踩坑记录：

第一次焊接的时候，烙铁头不上锡，焊点跟泥巴一样糊在一起。后来才知道新烙铁要先"吃锡"，拿焊锡丝在烙铁头上裹一层。焊的时候先加热焊盘和引脚，再把焊锡丝凑上去，大概2秒就融化了，焊点又亮又圆。

还有一个坑：焊LED的时候没看正负极，焊完不亮，拆下来重新焊才搞定。后来养成习惯，焊之前用万用表量一下，或者找板子上的丝印标记。

6. 嵌入式计算

开发板： ESP32

练习项目：舵机控制 / LED灯控制

示例代码：控制舵机摆动

#include <Servo.h>
Servo myServo;

void setup() {
    myServo.attach(9);
}

void loop() {
    myServo.write(0);
    delay(1000);
    myServo.write(90);
    delay(1000);
    myServo.write(180);
    delay(1000);
}

💡 踩坑记录：

焊接的时候手抖，烙铁在开发板上多停了两秒，直接把焊盘烫掉了。板子上的铜皮翘起来，再也焊不上。后来上网查才知道，烙铁温度不能太高（350℃左右就行），每个焊点控制在2-3秒，不行就等凉了再焊。

最后换了一块新板子，先在废板子上练了半小时，手稳了再焊正式项目。

7. 中期创客项目

项目名称：8*8点阵表情轮播呼吸灯

团队成员：李露、吴桐

项目介绍：一款8*8点阵表情轮播呼吸灯，能展现有趣的各种表情。

我的分工：3D模型的建立及模型的产出

制作过程：

  1. 需求分析：想做一个小灯牌，能轮流显示不同表情，灯光要有呼吸效果。
  2. 方案设计：用WS2812灯珠做8x8灯板，Arduino Nano做主控。
  3. 原型搭建：先用面包板测试，成功后再扩展到整个灯板。
  4. 代码编写：用FastLED库驱动，用millis()实现呼吸效果。
  5. 外壳设计：用SolidWorks画方形外壳，3D打印出来。
  6. 整机调试：补焊虚焊灯珠，调整渐变曲线。

💡 踩到的坑及解决：

  • 问题：呼吸效果用delay()写，切换表情时会卡顿。
    解决：改用millis()非阻塞定时。
  • 问题：外壳打印出来尺寸不对，盖子盖不上。

    解决：预留2mm空隙，重新打印。

9. 设计思维

设计思维的五个阶段：

  1. 共情：观察用户，了解需求
  2. 定义：明确要解决的问题
  3. 构思：头脑风暴，产生创意
  4. 原型：快速做出原型
  5. 测试：让用户测试，收集反馈迭代

我的练习：针对"宿舍生活不方便"的问题，进行小组讨论，发现"床上关灯不方便"是高频痛点，基于此设计了一个床头灯控制器。

10. 期末创新项目

项目名称：智能床头灯（暂定）

团队成员：李露、吴桐

项目背景：解决宿舍床上关灯不方便、缺乏氛围感的问题。

功能介绍：

  • 触摸/语音控制开关
  • 亮度无极调节 + 色温切换
  • 定时关灯 / 小夜灯模式

技术方案：

  • 主控芯片：ESP32
  • 传感器：触摸感应 / 麦克风模块
  • 执行器：PWM调光LED
  • 通信方式：蓝牙（手机控制）

项目总结与反思：设计过程中遇到供电发热问题，后期会增加散热和外壳通风。整体实现了远程控制 + 氛围感，后续可增加环境光自适应功能。
