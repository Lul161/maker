5. 电子焊接

焊接练习：LED闪烁电路

焊接步骤：

  1. 准备工具：电烙铁、焊锡、松香、助焊剂
  2. 给电烙铁预热（约300°C）
  3. 先给焊盘和元件脚上锡
  4. 将元件固定在电路板上
  5. 焊接每个焊点，约2-3秒
  6. 检查有无虚焊、短路

💡 踩坑记录：

第一次焊接的时候，烙铁头不上锡，焊点跟泥巴一样糊在一起。后来才知道新烙铁要先"吃锡"，拿焊锡丝在烙铁头上裹一层。焊的时候先加热焊盘和引脚，再把焊锡丝凑上去，大概2秒就融化了，焊点又亮又圆。

还有一个坑：焊LED的时候没看正负极，焊完不亮，拆下来重新焊才搞定。后来养成习惯，焊之前用万用表量一下，或者找板子上的丝印标记。

💡 踩坑记录：

焊接的时候手抖，烙铁在开发板上多停了两秒，直接把焊盘烫掉了。板子上的铜皮翘起来，再也焊不上。后来上网查才知道，烙铁温度不能太高（350℃左右就行），每个焊点控制在2-3秒，不行就等凉了再焊。

最后换了一块新板子，先在废板子上练了半小时，手稳了再焊正式项目。

7. 中期创客项目

项目名称：8*8点阵表情轮播呼吸灯

团队成员：李露、吴桐

项目介绍：一款8*8点阵表情轮播呼吸灯，能展现有趣的各种表情。

我的分工：3D模型的建立及模型的产出

制作过程：

  1. 需求分析：想做一个小灯牌，能轮流显示不同表情（笑脸、爱心、眨眼、哭脸等），灯光要有呼吸效果（渐亮渐暗循环）。
  2. 方案设计：用 FC-16 型号的 8x8 LED 点阵模块（MAX7219 驱动芯片），ESP32-C3 做主控，通过 MD_MAX72xx 库控制显示，SPI 通信。
  3. 原型搭建：先连接单块点阵模块测试显示单个图案，确认 SPI 通信正常后，再扩展图案库和呼吸逻辑。
  4. 代码编写：用 MD_MAX72xx 库驱动点阵，定义 12 组 8x8 像素图案（表情 + 图标），用 for 循环控制亮度寄存器实现呼吸效果，切换图案间加短暂延时。
  5. 外壳设计：用 SolidWorks 画方形外壳，正面开窗露出点阵屏幕，背面留出主控板固定位和供电口，3D 打印出来。
  6. 整机调试：调整 MIN_BRIGHTNESS 和 MAX_BRIGHTNESS 优化呼吸范围，修改 BREATH_DELAY 控制呼吸速度，确保图案切换流畅无闪烁。

核心代码（驱动8x8点阵 + 呼吸效果）：

#include <MD_MAX72xx.h>
#include <SPI.h>

#define HARDWARE_TYPE MD_MAX72XX::FC16_HW
#define MAX_DEVICES 1

#define DATA_PIN 11
#define CLK_PIN  12
#define CS_PIN   10

MD_MAX72XX mx = MD_MAX72XX(HARDWARE_TYPE, DATA_PIN, CLK_PIN, CS_PIN, MAX_DEVICES);

#define MIN_BRIGHTNESS 0
#define MAX_BRIGHTNESS 10
#define BREATH_DELAY 45
#define BREATH_TIMES 2

// 笑脸图案
const byte faceSmile[8] = {
  B00111100, B01000010, B10100101, B10000001,
  B10100101, B10011001, B01000010, B00111100
};

// 爱心图案
const byte faceHeart[8] = {
  B00000000, B01100110, B11111111, B11111111,
  B11111111, B01111110, B00111100, B00011000
};

// 惊讶脸
const byte faceWow[8] = {
  B00111100, B01000010, B10100101, B10000001,
  B10011001, B10011001, B01000010, B00111100
};

// 眨眼脸
const byte faceWink[8] = {
  B00111100, B01000010, B10100001, B10000001,
  B10100101, B10011001, B01000010, B00111100
};

// 哭脸
const byte faceCry[8] = {
  B00111100, B01000010, B10100101, B10000001,
  B10011001, B10100101, B01000010, B00111100
};

// 方块
const byte iconBox[8] = {
  B11111111, B10000001, B10000001, B10000001,
  B10000001, B10000001, B10000001, B11111111
};

// 箭头
const byte iconArrow[8] = {
  B00011000, B00011100, B11111110, B11111111,
  B11111110, B00011100, B00011000, B00000000
};

// 星星
const byte iconStar[8] = {
  B00011000, B01011010, B00111100, B11111111,
  B00111100, B01011010, B00011000, B00000000
};

// 音符
const byte iconMusic[8] = {
  B00011110, B00010010, B00010010, B00010010,
  B01110010, B11110010, B11100000, B01000000
};

// 小房子
const byte iconHouse[8] = {
  B00011000, B00111100, B01111110, B11111111,
  B11011011, B11011011, B11111111, B00000000
};

// 闪电
const byte iconLightning[8] = {
  B00001100, B00011000, B00110000, B01111100,
  B00011000, B00110000, B01100000, B00000000
};

// 钻石
const byte iconDiamond[8] = {
  B00011000, B00111100, B01111110, B11111111,
  B01111110, B00111100, B00011000, B00000000
};

// 图案列表
const byte* patterns[] = {
  faceSmile, faceHeart, faceWow, faceWink, faceCry,
  iconBox, iconArrow, iconStar, iconMusic,
  iconHouse, iconLightning, iconDiamond
};

const int patternCount = sizeof(patterns) / sizeof(patterns[0]);

void setup() {
  delay(500);
  mx.begin();
  mx.control(MD_MAX72XX::SHUTDOWN, false);
  mx.control(MD_MAX72XX::TEST, false);
  mx.control(MD_MAX72XX::INTENSITY, MIN_BRIGHTNESS);
  mx.clear();
}

void loop() {
  for (int i = 0; i < patternCount; i++) {
    showBitmap(patterns[i]);
    breathEffect(BREATH_TIMES);
    delay(200);
  }
}

// 显示 8x8 图案
void showBitmap(const byte image[8]) {
  mx.clear();
  for (int row = 0; row < 8; row++) {
    for (int col = 0; col < 8; col++) {
      bool pixelOn = bitRead(image[row], 7 - col);
      mx.setPoint(row, col, pixelOn);
    }
  }
}

// 呼吸灯效果
void breathEffect(int times) {
  for (int t = 0; t < times; t++) {
    // 渐亮
    for (int brightness = MIN_BRIGHTNESS; brightness <= MAX_BRIGHTNESS; brightness++) {
      mx.control(MD_MAX72XX::INTENSITY, brightness);
      delay(BREATH_DELAY);
    }
    // 渐暗
    for (int brightness = MAX_BRIGHTNESS; brightness >= MIN_BRIGHTNESS; brightness--) {
      mx.control(MD_MAX72XX::INTENSITY, brightness);
      delay(BREATH_DELAY);
    }
  }
}

💡 踩到的坑及解决：

  • 问题：呼吸效果用delay()写，切换表情时会卡顿。
    解决：改用millis()非阻塞定时。
  • 问题：3D打印尺寸没设计好，东西放不进去。

    解决：重新设计了一个稍微大一点的尺寸。
  • 问题：外壳打印出来尺寸不对，盖子盖不上。

    解决：预留2mm空隙，重新打印。

接线要点：

  • 所有外设与主控板采用母对公杜邦线直接连接，减少面包板使用，降低接触故障概率。
  • 无源蜂鸣器需串联 220Ω 限流电阻，防止 GPIO 引脚因过流损坏。
  • TFT 彩屏、土壤湿度传感器统一接入 5V 供电，3.3V 供电易出现工作异常。
  • 所有模块的 GND 引脚必须与 ESP32-C3 共地，避免信号漂移。
  • 彩屏 SCLK、MOSI 引脚严格按照定义接线，接反会导致屏幕无法点亮。
