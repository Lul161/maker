2. 什么是创客

创客（Maker） 是指那些勇于创新、动手实践的人。他们不满足于现成的产品，而是通过自己的努力，将想法变成现实。

创客精神包括：

  • 🔧 动手实践：把想法做出来
  • 🤝 分享协作：开源精神，与他人分享成果
  • 💡 持续学习：不断探索新技术
  • ⚡ 解决问题：用技术解决实际问题

我的创客座右铭："Make it happen!"

5. 电子焊接

焊接练习：LED闪烁电路 / 温度传感器模块

焊接步骤：

  1. 准备工具：电烙铁、焊锡、松香、助焊剂
  2. 给电烙铁预热（约300°C）
  3. 先给焊盘和元件脚上锡
  4. 将元件固定在电路板上
  5. 焊接每个焊点，约2-3秒
  6. 检查有无虚焊、短路

6. 嵌入式计算

开发板：Arduino Uno / ESP32

练习项目：舵机控制 / 超声波测距 / LED灯带控制

示例代码：控制舵机摆动

#include <Servo.h>
Servo myServo;

void setup() {
    myServo.attach(9);   // 信号线接数字引脚9
}

void loop() {
    myServo.write(0);    // 转到0度
    delay(1000);
    myServo.write(90);   // 转到90度
    delay(1000);
    myServo.write(180);  // 转到180度
    delay(1000);
}

8. PCB设计

设计软件：立创EDA / Altium Designer

练习内容：设计了一个LED灯板 / 传感器转接板

PCB设计流程：

  1. 绘制原理图，连接元件引脚
  2. 检查电气规则（ERC）
  3. 导入到PCB设计界面
  4. 布局元件，按功能分区
  5. 布线（先走电源线，再走信号线）
  6. 添加泪滴、铺铜
  7. 生成Gerber文件，发厂家打样

9. 设计思维

设计思维的五个阶段：

  1. 共情（Empathize）：观察用户，了解需求
  2. 定义（Define）：明确要解决的问题
  3. 构思（Ideate）：头脑风暴，产生创意
  4. 原型（Prototype）：快速做出原型
  5. 测试（Test）：让用户测试，收集反馈迭代

我的练习：针对“宿舍生活不方便”的问题，进行用户访谈，发现“床上关灯不方便”的需求，设计了一个床头灯控制器。
